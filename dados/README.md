# Bases

Não versione os CSVs. Obtenha `asteroid_dataset_20251019.csv` e `games.csv` usados no Projeto 1 e coloque-os neste diretório com os nomes:

- `asteroids.csv`
- `games.csv`

No clone local em que o repositório do Projeto 1 está ao lado deste, pode-se criar links:

```sh
ln -s ../../Busca_Organizacao_Dados/asteroid_dataset_20251019.csv asteroids.csv
ln -s ../../Busca_Organizacao_Dados/games.csv games.csv
```

Os exemplos usam cabeçalhos `asteroid_designation`, `year`, `on_sentry_list`, `AppID` e `Name`, conferidos nos CSVs do Projeto 1. O leitor `games` divide o cabeçalho combinado `DiscountDLC count`, preservando a linha original na exportação.
